# kaizo 改造

Small mods for Claude Code.

## Install

```
/plugin marketplace add nmicovic/kaizo
/plugin install neongai@kaizo
```

## Mods

| Mod | What it does | Status |
|---|---|---|
| **neongai** ネオン街 | A neon synthwave scene in a side pane that shows what Claude is doing | in progress |
